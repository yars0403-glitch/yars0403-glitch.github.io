このアプリについて

「はてな博士 分析」は、ユーチューブチャンネル「はてな博士」の運営者本人だけが使う、個人用の分析の道具です。

使うデータ

  • 運営者本人のユーチューブチャンネルの数字(再生数・視聴時間・視聴維持率・表示回数・クリック率・高評価・コメント・登録者数など)
  • だれでも見られる、ほかのチャンネルの公開されている数字(再生数・題名など)

グーグルから受け取る許可は「読むだけ」(yt-analytics.readonly と youtube.readonly)です。動画の投稿・変更・削除はしません。

使い方

  • 運営者が、次の動画の内容を良くするためだけに使います。
  • ほかの人や会社に売ったり、渡したりしません。広告にも使いません。
  • 細かい数字は分析のあいだだけ使い、長く残しません。残すのは「学んだこと」の短いまとめだけです。
  • コメントは分析だけに使い、書いた人の名前などを外に出しません。

許可の取り消し

グーグルアカウントの「セキュリティ」の「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

このアプリによるグーグルのデータの扱いは、Google API サービスのユーザーデータに関するポリシーとYouTube API サービス利用規約に従います。ユーチューブの利用にはYouTube 利用規約が、グーグルによるデータの扱いにはGoogle プライバシー ポリシーが適用されます。
